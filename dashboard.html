Import products from CSV
Bulk-add products from a spreadsheet. Each row becomes one product. Existing SKUs are skipped, so re-importing is safe. Variants aren't supported yet — one row = one simple product.
Optional — any CSV works, since you'll match columns in Step 3. Template columns: name, description, category, price, sku, quantity, compareAtPrice, brand, weight, imageUrls, status. Only name, category, price, sku are required.
Photos are added as web links, not files. In the imageUrls column paste a public image address (e.g. https://…/photo.jpg) — handy if your products are already on Shopify, eBay, Etsy or a website (right-click a photo → “Copy image address”). Put several in one cell separated by a space or |. Leave it blank to add photos later. To upload photo files from your computer, use the normal Add product screen instead.
Any CSV works — you'll match its columns to ShopSell's fields in the next step, so you don't need to rename anything.
